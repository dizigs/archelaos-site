# Fact Check — participatory museum research

This is **not** a scored quiz and has no answer key. The museum now contains all 61 historical *dilemmas* TF001–TF061 from the private research bank, published only as unverified questions. **No PDF details, internal research notes, raw source citations, private files or private contributor details are included.**

## Workflow
- Site: /history.html#arch-factcheck-promo — embedded in the live museum and rebuild copy.
- Visitor chooses Σωστό / Λάθος / Δεν γνωρίζω; optionally adds a memory/evidence URL; verifies Turnstile; private pending-only insert.
- Cloudflare Pages API: functions/api/fact-check.js, with binding FACTCHECK_DB, secret TURNSTILE_SECRET, and a dedicated EU-jurisdiction D1 database. Non-ready is fail closed and explicitly shown to users. No public tally or history edits.
- D1 migration: docs/migrations/20261107_factcheck_responses.sql. Production table and indexes created via Cloudflare API on 2026-11-07, with no user data.
- Moderation: reviewer reads D1 privately; claims only change status after examining independent material. No response/poll is evidence by itself. Identity/portrait/right issues need more care before becoming historical facts.
- Privacy: no account, name, email, IP, cookies or analytics generated by this feature; visitor-supplied note/source are kept privately and require moderation. Turnstile is used against abuse. No public aggregate count.
- Existing popup corrections PR #242 remains separate and inactive; do not merge/change it to publish this feature.
- Production release requires exact-HEAD protected checks, merge to main, and Cloudflare Pages deployment proof. Never infer release from PR success alone.
