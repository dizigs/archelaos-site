## Στάδιο 1 — Κοινά στοιχεία (σε εξέλιξη)

- \`css/tokens.css\`: μοναδικές τιμές χρωμάτων, αποστάσεων και διαστάσεων.
- \`css/components.css\`: βασική οπτική γλώσσα για header, footer, κάρτες και popups.
- \`js/shell.js\`: ένα header, ένα μενού και ένα footer, με mobile drawer.
- \`js/components.js\`: επαναχρησιμοποιούμενες καρτέλες και ένα προσβάσιμο popup μέσω native dialog.
- \`preview.html\`: **εσωτερικό δοκιμαστικό**, όχι αντικατάσταση της αρχικής.

## Κανόνες συνέχειας

1. Διατηρούμε κείμενα, εικόνες και στοιχεία αρχείου. Δεν συντάσσουμε επινοημένα ιστορικά δεδομένα.
2. Η εμφάνιση των καρτών πρέπει να ακολουθεί το backup: χρονολογία πάνω αριστερά, κεντραρισμένος τίτλος, διακριτική χρονολογία κάτω δεξιά, ένα λοξό βέλος, χωρίς χρυσή αριστερή λωρίδα.
3. Μενού/footer/dialogs δημιουργούνται μία φορά· όχι αντιγραφή HTML/JS σε κάθε σελίδα.
4. Κάθε σελίδα συγκρίνεται σε desktop/mobile με την αντίστοιχη του backup προτού προχωρήσουμε.
5. Κρατάμε παλιές διαδρομές και SEO. Η \`preview.html\` είναι \`noindex\`.
6. Οι παλιές βιβλιοθήκες και CSS δεν μεταφέρονται αυτομάτως. Αν κάποιο παλιό component είναι χρήσιμο, μεταφέρουμε τη σχεδίαση καθαρά και ελεγχόμενα.
7. Όσα στοιχεία προέκυψαν μετά το backup εξετάζονται ξεχωριστά για περιεχόμενο και διορθώσεις, όχι ως νέα οπτική βάση.
