# Προαιρετική τεκμηριωμένη σύνοψη στην αναζήτηση

Η υπάρχουσα αναζήτηση λειτουργεί **πάντα τοπικά χωρίς API**. Το πλαίσιο
`#sr-ai` στο `rebuild/search.html` έχει `data-enabled="false"` και
παραμένει αόρατο. **Δεν** έχουμε ενεργοποιήσει AI υπηρεσία ή χρέωση.

Ο υποψήφιος Cloudflare Worker `rebuild/ai/worker.js` χρησιμοποιεί
**μόνο δημόσια JSON** από `archelaos.club`: πρόσωπα, 70 στιγμές,
ιστορίες, εκθέματα, τμήματα, συνεντεύξεις, εγκεκριμένους αγώνες.
Δεν έχει δικαιώματα Google Drive ή write/update σε βάσεις.

## Ενεργοποίηση μόνο μετά από πραγματική επαλήθευση
1. Επιβεβαίωση μη κερδοσκοπικού δικαιώματος, υπολοίπου credits,
   διαθέσιμου μοντέλου και **συνολικού ορίου 10 €/μήνα**.
2. Δημιουργία ξεχωριστής υπηρεσίας Worker, route `/api/ask`,
   με Workers AI binding `AI`, επιλεγμένο `AI_MODEL`,
   Cloudflare rate limiting binding `AI_LIMITER`,
   D1 `AI_QUOTA_DB` με τη migration `0001_quota.sql`,
   `DAILY_AI_REQUEST_CAP` (προτείνεται 10–20/ημέρα) και
   `AI_ENABLED=true` **μόνο μετά τις δοκιμές**.
3. Πριν από την ενεργοποίηση, όριο δαπανών με πραγματική συμπεριφορά
   fail-closed σε επίπεδο παρόχου· το D1 request cap ελέγχει αριθμό
   ερωτήσεων, **όχι χρηματικές χρεώσεις**. Εάν δεν υπάρχει ασφαλής
   μηχανισμός, μη συνδέσετε πληρωμένη υπηρεσία.
4. Μόνο έπειτα αλλαγή `data-enabled="true"` στη σελίδα αναζήτησης,
   smoke test στο κινητό, έλεγχος 429/503 και παραπομπών.
5. Azure AI μπορεί να χρησιμοποιηθεί αντί για Workers AI με ξεχωριστό
   adapter, auth και ακριβώς τα ίδια όρια/ιδιωτικότητα. Δεν είναι
   fallback που ενεργοποιείται αυτόματα.

Η σύνοψη καλείται μόνο μετά από ρητό πάτημα «Σύνθεση απάντησης»,
ποτέ σε κάθε πληκτρολόγηση, και δεν υπάρχει chatbot.
