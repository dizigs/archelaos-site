# Εσωτερικό μητρώο ιστορικών γεγονότων — Γ.Α.Σ. Αρχέλαος

## Σκοπός
Αντί για δεύτερη δημόσια σελίδα «Ιστορικά Γεγονότα», διατηρούμε οργανωμένο **ερευνητικό μητρώο** στο \`rebuild/research/historical-events.json\`. Δεν αντιγράφεται στο παραγόμενο \`dist/\`, δεν φορτώνεται από την ιστοσελίδα και **δεν** τροφοδοτεί αυτόματα τα βιογραφικά. Παραμένει ανοιχτή η δυνατότητα δημιουργίας μελλοντικών ενσωματωμένων «Σχετικών γεγονότων» στο Hall of Fame μόνο μετά από επιμελητική έγκριση.

**Σημαντικό:** Το GitHub repository είναι δημόσιο: ο φάκελος είναι «κρυφός» μόνο από τους επισκέπτες του site, **όχι ιδιωτικός από το GitHub**. Καταχωρίζουμε αποκλειστικά δημόσια ιστορικά στοιχεία και URLs. Ιδιωτικά πρακτικά, Drive IDs και ανεπίσημα έγγραφα δεν μπαίνουν εδώ.

## Δομή
- \`source_registry\`: πηγές με οργανισμό, τίτλο, HTTPS URL, ημερομηνία ελέγχου και είδος πηγής.
- \`events\`: σταθερό ID γεγονότος, τύπος, άθλημα, τίτλος, σύντομη τεκμηριωμένη περιγραφή, **ακριβής ημερομηνία ή σαφής αγωνιστική περίοδος** χωρίς κατασκευή ημερομηνίας, πηγές, σύνδεση με σχετικές στιγμές και συνδεδεμένα πρόσωπα με σταθερό Hall-of-Fame ID, ρόλο και παραπομπή.
- \`review_flags\`: πραγματικές διαφορές ανάμεσα στις δημόσιες πηγές και σε υπάρχοντα κείμενα, με συγκεκριμένο ID της σχετικής από τις 70 Στιγμές. Οι διαφορές παραμένουν προς επιμελητική αξιολόγηση, δεν διορθώνονται αυτόματα.
- \`policies\`: ρητή απενεργοποίηση αυτοδημοσίευσης και αυτόματης συλλογής ειδήσεων.

Αρχική έρευνα 31/10/2026: κύπελλα 1984, 1990, 1993, 1994 (ΟΧΕ και αθλητικός Τύπος), ευρωπαϊκοί αγώνες 1994, 1995, 1996, 2000 (EHF), ιστορικό φωτογραφικό 1983–84 (KateriniSport) και τίτλοι Παίδων/Μίνι 1994–95 (ΟΧΕ). Τα ονόματα παικτών/προπονητή στο φωτογραφικό άρθρο αντιστοιχίζονται **μόνο με ακριβές υπάρχον μοναδικό ID** της βάσης, σε σαφή ρόλο.

## Σημαντικές ιστορικές ασυμφωνίες προς έλεγχο
1. Στιγμή #45: σκορ τελικού 1984 «18–24» έναντι **21–19** στους πίνακες ΟΧΕ και ΣΠΟΡ FM.
2. Στιγμή #63: περιγράφει αποκλεισμό Borec από τον Αρχέλαο το 1994, ενώ η EHF δίνει 13–22 και 22–18 — **συνολικό 35–40, πρόκριση Borec**.
3. Στιγμή #63: η Fotex Veszprém αποδίδεται στη σεζόν 1994–95, αλλά η EHF καταγράφει τα παιχνίδια **Οκτώβριο 1996**.
4. Στιγμή #44: η χρονιά ανόδου στην Α΄ και η πρώτη χρονιά συμμετοχής συγχέονται. Το ιστορικό άρθρο διακρίνει την άνοδο 1982–83 από τη συμμετοχή 1983–84.

Αυτά είναι ευρήματα **σύγκρισης**, όχι άδεια αυτόματης αλλαγής. Παραμένουν αναλυτικά στο \`review_flags\`.

## Προσθήκη νέου ιστορικού γεγονότος
1. Αναζήτηση ιστορικών πηγών (όχι γενικών σημερινών ειδήσεων), π.χ. «ΓΑΣ Αρχέλαος Κατερίνης» + άθλημα/χρονιά/αθλητής, «Αρχέλαος Κατερίνης», «GAS Arhelaos Katerini», ομοσπονδίες ΟΧΕ/ΣΕΓΑΣ/EHF.
2. Επιβεβαίωση από την πρωτογενή ομοσπονδία ή πολλαπλές αξιόπιστες δημοσιεύσεις, κρατώντας ακριβές URL και ελάχιστη παραφρασμένη περιγραφή.
3. Έλεγχος αν ήδη υπάρχει γεγονός ή στιγμή με ίδιο αντίπαλο, ημέρα, σκορ, χρονιά, περίοδο και άθλημα. Αποφυγή διπλοεγγραφών.
4. Σύνδεση με πρόσωπο μόνο αν η πηγή κατονομάζει **τον ίδιο άνθρωπο στον ίδιο ρόλο για το γεγονός** και ταυτοποιείται με μοναδικό Hall-of-Fame ID. Αλλιώς **κενή λίστα προσώπων** και προτεινόμενο review.
5. Καταχώριση στο μητρώο, σύνδεση source_ids και έλεγχος:
\`\`\`sh
python rebuild/tests/verified_events.py
python rebuild/tools/validate_verified_events.py --json rebuild/test-artifacts/verified-events-report.json
python rebuild/tools/build_release.py
python rebuild/tools/verify_release.py
\`\`\`
6. Εφόσον ελεγχθούν αντιφάσεις και μεταφράσεις, οι εγκεκριμένες συνδέσεις θα μπορούν αργότερα να προβληθούν σε υπάρχοντα popups, **χωρίς δημιουργία ξεχωριστής σελίδας**.

Δεν προστίθεται crawler ή αυτόματη ροή ειδήσεων. Κάθε νέα εξωτερική έρευνα είναι στοχευμένη, με πηγές και έλεγχο της αξιοπιστίας τους.
