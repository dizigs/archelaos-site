# Βάση βιογραφικών — canonical και ιστορικό αρχείο

**Ενεργή δημόσια πηγή:** το `hall-of-fame-people.json` στη ρίζα του repository. Το `archelaos-person-index.json` πρέπει να περιέχει τα ίδια μοναδικά person IDs, ενώ το release build δημιουργεί τις αντίστοιχες σελίδες `/people/<id>.html` και διατηρεί SEO, συνδέσεις και ιστορικές ανακατευθύνσεις.

Το `rebuild/data/people.json` είναι **παλαιότερο αρχειακό στιγμιότυπο της ανακατασκευής**, όχι η ενεργή κύρια πηγή και **όχι όριο δημοσίευσης 682 προσώπων**. Δεν πρέπει να αντιγράφεται επάνω στην κανονική βάση ή να χρησιμοποιείται για να περικόπτονται νεότερες εγγραφές. Οι offline μεταφράσεις της περιόδου έχουν διαφορετική κάλυψη και δεν ενεργοποιούν εναλλαγέα γλώσσας.

**Επιβεβαιωμένη κατάσταση στις 3 Νοεμβρίου 2026:** 763 πρόσωπα στην canonical βάση, 763 IDs στο ευρετήριο, 682 εγγραφές στο παλιό staged αρχείο. Η canonical βάση έχει 81 επιπλέον IDs και κανένα ID του staged αρχείου δεν λείπει από την canonical. Σε 57 κοινά IDs διαφέρει το ελληνικό `bio`, σε 32 το αγγλικό `bio_en` (οι ομάδες επικαλύπτονται). Σε ένα κοινό ID (`arch-f56820c52e55`) υπάρχει παλιά ανορθογραφία στο stage: σωστό **Χρήστος Λιμπανοβνός**, όχι «Λυμπανοβνός».

Κάθε μελλοντική αλλαγή πρέπει να ελέγχει IDs, source URLs, person aliases, `news.json`, `archelaos-history-events.json`, ατομικά HTML, sitemap και αγαπημένα. Αποφεύγουμε direct push στο `main`: απαιτούνται PR, οι προβλεπόμενοι έλεγχοι CI και επιβεβαίωση πραγματικών Cloudflare production logs.

Η παλαιότερη απογραφή `docs/research/hall-parity-20261103.md` τεκμηριώνει *προγενέστερο στιγμιότυπο* 760/682. Δεν πρέπει να χρησιμοποιείται σαν σημερινός μετρητής.
