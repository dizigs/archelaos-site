# Αγωνιστικό πρόγραμμα από ημερολόγια χάντμπολ / βόλεϊ

Το εργαλείο προετοιμάστηκε **χωρίς** να έχουμε ακόμη πραγματικά προγράμματα. Δεν εμφανίζουμε επινοημένους αγώνες.

## Εισαγωγή
Ο ιδιοκτήτης εξάγει από Google Calendar, Apple Calendar ή Outlook ένα \`.ics\` ή ZIP με αρχεία \`.ics\`. Στέλνει τα αρχεία στη συνομιλία ή στον ασφαλή χώρο επεξεργασίας. Ο συνεργάτης αναγνωρίζει ποιο αρχείο αφορά χάντμπολ και ποιο βόλεϊ (δεν το μαντεύει).

\`\`\`sh
python rebuild/tools/import_match_calendar.py --handball /path/handball.ics --volleyball /path/volleyball.zip
\`\`\`

Η εντολή παράγει **μόνο** \`rebuild/test-artifacts/match-calendar-review.json\`, που αγνοείται από Git. Δεν τροποποιεί δημόσιο JSON και δεν κάνει commit/deploy.

Στη λίστα ελέγχου αναφέρονται ακριβώς τα SUMMARY, DTSTART, LOCATION, STATUS, μαζί με το αρχείο προέλευσης. Ελέγχουμε με επίσημο πρόγραμμα αντιπάλους, έδρα, ημερομηνία, ώρα, κατηγορία/ηλικιακό τμήμα, διοργάνωση, γήπεδο και αλλαγές. Άγνωστα πεδία παραμένουν άγνωστα. Αλλαγές σε UID, ακυρώσεις και επαναλήψεις δεν δημοσιεύονται αυθαίρετα.

## Προβλήματα που αντιμετωπίζονται προληπτικά

- RFC 5545 folded lines, escaped κείμενο, UTF-8, ημερομηνίες UTC και Europe/Athens.
- Τοπικές «floating» ώρες, all-day events, αλλαγές θερινής ώρας, αμφίσημη ώρα Οκτωβρίου σημειώνονται για ανθρώπινο έλεγχο.
- \`RRULE\`, \`RECURRENCE-ID\`, \`RDATE\`, \`EXDATE\` **δεν** μετατρέπονται σε έναν τυχαίο επόμενο αγώνα. Ζητούν εξαγωγή σε μονές αγωνιστικές εγγραφές.
- Πολλαπλά αρχεία ZIP και επαναλαμβανόμενα ίδια UID, ακυρωμένοι αγώνες, γήπεδα ή αντίπαλοι που άλλαξαν.
- ZIP traversal, πολύ μεγάλα αρχεία, μη εξουσιοδοτημένη δημόσια εισαγωγή, προσωπικά δεδομένα σε DESCRIPTION: διαβάζουμε μόνο ελάχιστα metadata και δεν αποθηκεύουμε περιγραφές/email.
- Όλοι οι πραγματικοί αγώνες απαιτούν τελική επιμελητική απόφαση πριν την ένταξη στο δημόσιο \`match-schedule.json\`.

## Μελλοντική δημόσια εμφάνιση
Η αρχική θα δείχνει λίγους επόμενους **εγκεκριμένους** αγώνες με φίλτρα χάντμπολ/βόλεϊ, ημερομηνία/ώρα Ελλάδας, ομάδες, διοργάνωση, γήπεδο, και δυνατότητα προσθήκης σε προσωπικό ημερολόγιο. Οποιαδήποτε αλλαγή θέλει επανέλεγχο. Οι περασμένοι αγώνες εξαφανίζονται από τη λίστα αυτόματα με βάση την τοπική ώρα, χωρίς να διαγράφονται από το αρχείο.

Μία σταθερή διεύθυνση \`/calendar.ics\` μπορεί να χρησιμοποιηθεί για συνδρομή ημερολογίου, όταν υπάρχουν εγκεκριμένα δεδομένα. Λήψη ενός αρχείου ICS είναι στιγμιότυπο, συνδρομή μέσω ημερολογίου μπορεί να ενημερώνεται ανάλογα με τη συμπεριφορά του πελάτη.

Πρωτόκολλο: https://www.rfc-editor.org/rfc/rfc5545.html


## Matchday — σχεδιαστική εμπειρία (έτοιμη στον δοκιμαστικό κλάδο)

Η αρχική προβάλει μια **μεγάλη ιστορική ενότητα** αντί για τυπικό πλαίσιο ημερολογίου: πράσινο φόντο, χρυσές λεπτομέρειες, τυπογραφία με χαρακτήρα και έντονη σύνδεση με το **1956–2026**. Όταν δεν υπάρχουν εγκεκριμένοι αγώνες, υπάρχει επιμελημένο μήνυμα αναμονής — όχι ψεύτικες ομάδες ή ημερομηνίες.

Κάθε εγκεκριμένος αγώνας εμφανίζει ξεχωριστά γηπεδούχο, φιλοξενούμενο, ημερομηνία/ώρα Ελλάδας, διοργάνωση και γήπεδο εφόσον έχουν επιβεβαιωθεί. Ο επισκέπτης επιλέγει **«Στο δικό μου ημερολόγιο»**:
- Ατομικό \`.ics\` στον σύνδεσμο \`/calendar/events/<match-id>.ics\` για Apple/Google/Outlook εισαγωγή, χωρίς να απαιτείται γνωστή ώρα λήξης.
- Άμεσο Google/Outlook add-event link **μόνο όταν υπάρχει εγκεκριμένη \`end_at\`**. Αν δεν υπάρχει, δεν επινοείται διάρκεια δύο ωρών.
- \`/calendar.ics\` με όλους τους εγκεκριμένους αγώνες για εισαγωγή ή συνδρομή. Αλλαγές ενδέχεται να εμφανίζονται με καθυστέρηση στον εκάστοτε calendar client.

Κάθε ατομικό ημερολόγιο διατηρεί σταθερό event UID για δυνατότητα αναγνώρισης τροποποιήσεων. Η υποψήφια έκδοση δεν αποστέλλεται αυτόματα σε Cloudflare και δεν ενημερώνει το live μέχρι τελικό release.
