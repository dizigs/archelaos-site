# Σχεδιασμός συντακτικού ελέγχου για ένα σύγχρονο αθλητικό αρχείο

## Τι λειτουργεί ήδη
Το `python rebuild/tools/editorial_audit.py` διαβάζει μόνο τα προτεινόμενα δημόσια JSON της νέας έκδοσης. Ελέγχει όλες τις βιογραφίες, τις 70 Στιγμές και τις ιστορίες, χωρίς να αλλάζει ούτε μία λέξη. Σημειώνει πιθανή λάθος γλώσσα, διπλές παραγράφους, ύποπτους χαρακτήρες, παρασκηνιακές σημειώσεις επιμέλειας, διπλά IDs, ανύπαρκτους συσχετισμούς και διπλούς τίτλους. Τα ευρήματα είναι **υποδείξεις** που χρειάζονται έλεγχο, όχι απόδειξη λάθους.

Η αναφορά διατηρείται ως ιδιωτικό artifact του GitHub Actions και δεν εμφανίζεται στους επισκέπτες.

## Μελλοντική προαιρετική επιμέλεια με AI
Αν επιλέξουμε να ενσωματώσουμε υπηρεσία AI, θα λειτουργεί μόνο σε ασφαλές περιβάλλον επεξεργασίας και χωρίς να περνά από τον browser του επισκέπτη. Τα κλειδιά API αποθηκεύονται σε secrets, **ποτέ** σε repository ή JavaScript. Δεν απαιτείται να ορίσουμε ακόμη υπηρεσία ή να κατασκευάσουμε API.

Δίνουμε στο μοντέλο **μόνο δημόσιο υποψήφιο κείμενο** μαζί με αξιόπιστα αποσπάσματα πηγών που έχουν εγκριθεί για επεξεργασία. Δεν ανεβάζουμε αυτούσια τα ιδιωτικά πρακτικά του Drive αυτομάτως. Ζητούμε:
- παρατηρήσεις ορθογραφίας, σύνταξης, διπλολογίας και σαφήνειας,
- σύγκριση ελληνικού και αγγλικού κειμένου, ονόματος, ιδιότητας και χρονικών στοιχείων,
- πιθανές αντιφάσεις για αγώνα/επίδοση/κατηγορία/προπονητή,
- προτεινόμενη μικρή διόρθωση με ακριβή θέση και ελάχιστη αναγκαία αλλαγή,
- αιτιολόγηση και αναφορά συγκεκριμένης πηγής ή την ένδειξη «δεν τεκμηριώνεται».

**Κανόνες:** Δεν επινοούμε μετάλλια, νίκες, ρεκόρ, χρονολογίες, δηλώσεις ή πηγές. Δεν διορθώνουμε ονόματα από εικασίες. Δεν χάνεται καμία συμμετοχή ή αθλητής από το αρχείο. Αλλαγές γίνονται μόνο μέσα από review και tests, ποτέ με απευθείας δημοσίευση από AI.

## Φόρμες και Resend — ρητό πάγωμα
Το markup, οι κατηγορίες ενδιαφέροντος και η θέση της φόρμας επικοινωνίας **μένουν όπως είναι**. Δεν αναπτύσσουμε προσωρινό API, proxy, Resend wrapper, Cloudflare Worker ή δεύτερη φόρμα τώρα. Η υφιστάμενη εναλλακτική mailto δεν είναι αποστολή από server. Όταν επιλεγεί τελικά το Resend, τότε θα σχεδιαστεί μία οριστική ασφαλής υποβολή με έλεγχο πεδίων, spam protection, privacy και secrets. Δεν αποθηκεύουμε προσωρινά μηνύματα στο site.

## Ασφαλής έλεγχος
```
python rebuild/tools/editorial_audit.py --json rebuild/test-artifacts/editorial-report.json
```
Οι συνηθισμένες επιμελητικές παρατηρήσεις δεν κόβουν το build. Τα δομικά σφάλματα ελέγχονται με `--strict`.
