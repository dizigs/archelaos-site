# Δημόσιες αναφορές για ΓΑΣ Αρχέλαος — ασφαλής προετοιμασία

Το `rebuild/tools/public_mentions.py` διαβάζει **μόνο** δημόσια RSS/Atom
από ρητά εγκεκριμένους hosts (Google News RSS, YouTube channel feeds)
και παράγει *υποψήφια* άρθρα με τίτλο, σύνδεσμο, ημερομηνία και πολύ
σύντομο απόσπασμα. Ποτέ δεν μεταφέρει στο site πρωτότυπο κείμενο
δημοσιεύματος, ούτε παράγει ή εγκρίνει αυτόματα ιστορικό ισχυρισμό.

Η προγραμματισμένη εργασία `.github/workflows/public-mentions.yml`
τρέχει δύο φορές την εβδομάδα. Το artifact είναι αποκλειστικά δημόσιας
προέλευσης και **δεν** περιέχει προσωπικά/ιδιωτικά στοιχεία.
Πριν από την ενσωμάτωση σε βιογραφία ή ιστορία απαιτείται ανάγνωση της
πρωτότυπης πηγής, αντιπαραβολή και συντακτική έγκριση.

Το `rebuild/research/public-mentions-sources.json` περιέχει τις
δηλωμένες στο site σελίδες Facebook και YouTube **ως εν αναμονή**.
Οι Instagram/Facebook αναρτήσεις δεν συλλέγονται μέσω scraping.
Για την ανάγνωση του επίσημου Page/Instagram Business χρειάζονται
κατάλληλα δικαιώματα Meta Graph API και νόμιμη σύνδεση/authorization.
Για δημόσιο YouTube channel feed χρειάζεται πρώτα επιβεβαιωμένο
`UC...` channel ID, όχι εικασία από το @handle.

Η τακτική ChatGPT αυτοματοποίηση ελέγχου του **ιδιωτικού** Drive
είναι ανεξάρτητη: δεν αντιγράφουμε Drive IDs, scans, ιδιωτικά πρακτικά
ή ενδεχόμενα ιατρικά δεδομένα στα δημόσια GitHub Actions.

Κατάσταση επεξεργασίας: `candidate_unverified` → ακριβής ανάγνωση
πηγής → αντιστοίχιση σε πρόσωπο/αγώνα/έτος → προσχέδιο →
έγκριση → ενημέρωση μέσω ελεγχόμενης ροής.
