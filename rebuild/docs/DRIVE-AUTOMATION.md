# Ασφαλής ροή εμπλουτισμού του αθλητικού αρχείου

Η αυτόματη καθημερινή παρακολούθηση του συνδεδεμένου Drive είναι **ξεχωριστή** από το δημόσιο GitHub. Ούτε το Cloudflare Pages ούτε τα public GitHub Actions έχουν πρόσβαση στα ιδιωτικά PDF, και αυτό δεν πρέπει να αλλάξει.

## Πρακτική ροή

1. Ο ιδιωτικός έλεγχος συγκρίνει νέα τεκμήρια με τις υπάρχουσες 682 βιογραφίες, 70 Στιγμές, 21 αρχικές ιστορίες και το Ψηφιακό Μουσείο.
2. Οι νέες πληροφορίες διασταυρώνονται με συγκεκριμένες πηγές και ετοιμάζεται *δημόσιο-ασφαλές* πρόχειρο χωρίς εσωτερικά Drive IDs, ευαίσθητα δεδομένα, ιδιωτικά links ή αντίγραφα πρακτικών.
3. Οι τεκμηριωμένες προτάσεις εισάγονται **μόνο στον δοκιμαστικό κλάδο**, με έλεγχο περιεχομένου και αποφυγή διπλοεγγραφών, όχι κατευθείαν στη δημόσια ιστοσελίδα.
4. Οι έλεγχοι GitHub Actions δοκιμάζουν ότι δεν χάθηκαν οι αρχικές εγγραφές, η αρίθμηση των 70 Στιγμών δεν άλλαξε, και οι 682 canonical σελίδες συνεχίζουν να λειτουργούν.
5. Καμία αυτόματη δημοσίευση ή πρόσβαση browser του επισκέπτη στα ιδιωτικά αρχεία.

## Χρήση εργαλείου

Το `rebuild/tools/ingest_verified.py` δεν προσεγγίζει το Drive. Διαβάζει μόνο πακέτο που έχει ήδη εγκριθεί για δημόσια χρήση.

```sh
python rebuild/tools/ingest_verified.py --input .archive-intake/reviewed.json
python rebuild/tools/ingest_verified.py --input .archive-intake/reviewed.json --apply
python rebuild/tests/ingestion.py
```

Η πρώτη εντολή είναι dry-run. Το `--apply` αλλάζει μόνο staged JSON, με δυνατότητα ανάκλησης μέσω Git και χωρίς deploy.

### Μορφή παραδείγματος

```json
{
  "schema_version": 1,
  "approval": {"status": "approved", "reviewed_by": "Υπεύθυνος αρχείου"},
  "entries": [{
    "operation": "biography_note",
    "verified": true,
    "safe_for_publication": true,
    "source_label": "Πρακτικό συλλόγου, έτος και σελίδα (χωρίς ιδιωτικό URL)",
    "person_id": "arch-xxxxxxxxxxxx",
    "paragraph_el": "Ακριβής τεκμηριωμένη προσθήκη στα ελληνικά.",
    "paragraph_en": "Verified English translation of the documented addition."
  }]
}
```

Επιτρεπόμενες πράξεις: `append_story` (προσθήκη ιστορίας στο τέλος, χωρίς αλλαγή των παλιών συνδέσμων), `biography_note` (εμπλουτισμός υπάρχουσας βιογραφίας στα ελληνικά/αγγλικά), `moment_addendum` (παράγραφος σε υπάρχουσα από τις 70 Στιγμές), `add_event` (νέο αυτόνομο τεκμηριωμένο γεγονός στο Ψηφιακό Μουσείο). Οι 70 Στιγμές παραμένουν 70.

**Δεν γίνονται άμεσες εισαγωγές ανεπιβεβαίωτων πληροφοριών ούτε αυτόματα uploads φωτογραφιών.** Τα αρχεία συνεισφοράς και οι φόρμες περιμένουν την οριστική λύση Resend.

### Διατήρηση πλήρων ατομικών βιογραφιών
Τα παλιά ξεχωριστά προφίλ συχνά έχουν εκτενέστερη αγγλική βιογραφία από την περίληψη του κεντρικού JSON. **Δεν την αντικαθιστούμε.** Οι νέες επαληθευμένες δίγλωσσες προσθήκες αποθηκεύονται επιπλέον στο `people-addenda.json`. Το build προσθέτει μόνο τις καινούργιες παραγράφους με δημόσια βιβλιογραφική αναφορά και στις 682 σταθερές διευθύνσεις, διατηρώντας πλήρως το πρωτότυπο περιεχόμενό τους. Αυτό ελέγχεται από `verify_release.py`.
