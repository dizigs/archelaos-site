# Πρόταση αυτοματισμών ιστορικού αρχείου — μη δημοσιευμένη αναφορά

## Υλοποιημένο: διασυνδέσεις ιστορικών συλλογών
Το script \`rebuild/tools/archive_opportunities.py\` διαβάζει μόνο τα ήδη δημόσια **staged** JSON:
- 682 βιογραφικά,
- 70 Στιγμές,
- ιστορίες,
- εκθέματα και αποκόμματα του Ψηφιακού Μουσείου,
- τεκμηριωμένες ημερομηνίες του «Σαν Σήμερα».

Εντοπίζει υποψήφιες **πλήρεις** αναφορές ονομάτων σε κείμενα χωρίς τόνους/κεφαλαία. Αποκλείει αμφίσημα πλήρη ονόματα που αντιστοιχούν σε διαφορετικά profile IDs. Δεν ερμηνεύει τα επώνυμα μόνα τους, ούτε τις αναφορές ως ιστορική απόδειξη ή αυτόματη ταυτοποίηση. Ετοιμάζει μόνο λίστα προς ανθρώπινη έγκριση.

\`\`\`sh
python rebuild/tests/archive_opportunities.py
python rebuild/tools/archive_opportunities.py --json rebuild/test-artifacts/archive-connections.json
\`\`\`

Το GitHub CI παράγει το artifact \`archelaos-archive-connections-review\`. Δεν αλλάζει ποτέ HTML, JSON ή public page, ούτε αντλεί ιδιωτικά αρχεία Drive. Οι συνδέσεις μπορούν αργότερα να εμφανίζονται σε βιογραφικό / ιστορία / έκθεμα **μόνο** αν κριθούν ορθές.

## Δεύτερη φάση (προτάσεις — όχι ακόμη υλοποιημένες)

1. **Ανά δεκαετία/άθλημα**: πραγματικός χάρτης πληρότητας και εντοπισμός κενών, χωρίς να παρουσιάζεται η απουσία δεδομένων ως απουσία αθλητικής δραστηριότητας.
2. **Επέτειοι με τεκμήριο**: επέκταση του υπάρχοντος \`on-this-day.json\` με ακριβώς επαληθευμένες ημερομηνίες μόνο, διασύνδεση με ιστορική στιγμή.
3. **Σύγκριση πληροφοριών**: εντοπισμός διαφορετικών χρονολογιών/ιδιοτήτων στο διοικητικό αρχείο, στις στιγμές και στα βιογραφικά ως *possible conflict*, όχι αυτόματη διόρθωση.
4. **Φωτογραφικό αρχείο**: sha256/perceptual duplicate candidates, διαστάσεις, διαχειρίσιμες λεζάντες, τεκμηριωμένα δικαιώματα. Τα εξωτερικά image links παραμένουν dependencies.
5. **Έτοιμο προς επιμέλεια αφιέρωμα**: συγκέντρωση κειμένων και επαληθευμένων δημόσιων πηγών σε προσχέδιο. Ποτέ αυτόματο γέμισμα επιδόσεων ή δημοσίευση.
6. **Μηνιαία αναφορά**: συγκεντρωμένα findings από ήδη υπάρχοντα CI και ασφαλείς ιδιωτικούς ελέγχους Drive, χωρίς εισαγωγή ιδιωτικού υλικού στο δημόσιο GitHub.

Η ιδιωτική επιτήρηση του Drive είναι ξεχωριστή. Δεν τοποθετούμε κωδικούς ή ιδιωτικά PDF σε workflow GitHub. Δεν δημιουργούμε αυτόματη ροή ειδήσεων από δημόσιες ιστοσελίδες.
