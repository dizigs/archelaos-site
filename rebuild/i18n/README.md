# Πολύγλωσσο αρχείο — μόνο προετοιμασία, καμία αυτόματη ενεργοποίηση

Η δημόσια ιστοσελίδα παραμένει στα **ελληνικά**. Στη δοκιμαστική έκδοση υπάρχουν μόνο **κρυφές θέσεις** για μελλοντική επιλογή γλωσσών στο desktop και στο mobile menu. Δεν εμφανίζεται κουμπί γλώσσας και καμία προσχέδια μετάφραση δεν δημοσιεύεται.

## Δομή
- `manifest.json`: δηλωμένες γλώσσες, στάδιο ελέγχου, ρητή απενεργοποίηση επιλογέα.
- `ui/el.json`, `ui/en.json`, `ui/de.json`, `ui/fr.json`, `ui/es.json`, `ui/it.json`: κείμενα πλοήγησης και διεπαφής.
- `content/en/people.json`: 682 υπάρχουσες αγγλικές περιγραφές από το ιστορικό αρχείο (όχι νέες μη επαληθευμένες μεταφράσεις).
- `content/en/moments.json`: 70 υπάρχουσες αγγλικές στιγμές.
- `content/en/coverage.json`: ουρά επιμέλειας. Οι αγγλικές βιογραφίες μπορεί να είναι συντομότερες από τα ελληνικά πρωτότυπα, ενώ οι 21 Ιστορίες δεν έχουν πλήρη αγγλική μετάφραση.
- Τα αγγλικά του Μουσείου και των Διοικήσεων βρίσκονται ήδη μέσα σε HTML του αρχειακού JSON και απαιτούν προσεκτική εξαγωγή.

Οι άλλες τέσσερις γλώσσες έχουν προς το παρόν **μόνο κείμενα πλοήγησης**. Δεν θεωρούνται πλήρεις μεταφράσεις ιστοσελίδας.

## Συντήρηση
```sh
python rebuild/tools/export_translations.py
python rebuild/tools/audit_translations.py
```

Η εξαγωγή αντιγράφει μόνο υπάρχον κείμενο και **δεν μεταφράζει αυτόματα**. Η ενεργοποίηση στο μέλλον απαιτεί ποιοτικό έλεγχο όλων των σελίδων, απόδοσης ονομάτων/πηγών, διαδρομών ανά γλώσσα, SEO hreflang και πραγματικές δοκιμές browser. Το `build_release.py` δεν δημοσιεύει αυτόν τον φάκελο.
