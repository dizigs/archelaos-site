ΜΙΑ ΜΙΚΡΗ ΕΞΟΜΟΛΟΓΗΣΗ

Η μνήμη δεν κατοικεί πάντα σε αρχεία.

Υπάρχουν ιστορίες που δεν γράφτηκαν ποτέ σε βιβλία. Ένα παιδί στον πρώτο του αγώνα. Μια ομάδα που κάποιοι τη θυμούνται ακόμη. Ένας προπονητής, μια παρέα, ένας άνθρωπος που πρόσφερε σιωπηλά.

Πίσω από κάθε συμμετοχή υπήρξαν κόποι, χαρές, απογοητεύσεις και όνειρα. Πολλές από αυτές τις στιγμές δεν έγιναν τίτλοι εφημερίδων. Κι όμως, αποτελούν κομμάτι της ιστορίας του Αρχέλαου.

Όταν ξεκινήσαμε να τις αναζητούμε, δεν βρήκαμε ένα τέλειο, τακτοποιημένο αρχείο. Βρήκαμε διάσπαρτα ίχνη, αναφορές, ονόματα και ανθρώπινες αναμνήσεις. Και καταλάβαμε ότι, αν περιμέναμε να έχουμε όλες τις αποδείξεις, ίσως να χάναμε ακόμη περισσότερα.

Μια ανάμνηση

Μια αφήγηση μπορεί να ανοίξει τον δρόμο για ένα χαμένο τεκμήριο — όχι να το αντικαταστήσει.

“

ΜΙΑ ΕΙΛΙΚΡΙΝΗΣ ΠΑΡΑΔΟΧΗ

Δεν ισχυριζόμαστε πως γνωρίζουμε όλη την αλήθεια.

Κάποιες ημερομηνίες μπορεί να είναι λανθασμένες. Κάποια ονόματα ίσως λείπουν. Ορισμένες αναμνήσεις δεν μπορούν ακόμη να διασταυρωθούν. Αυτό το Μουσείο δεν υπόσχεται 100% ιστορική ακρίβεια. Προσπαθεί να ξεχωρίζει τα τεκμηριωμένα γεγονότα από τις ενδείξεις και τις προσωπικές μαρτυρίες — και να διορθώνεται όσο μαθαίνουμε περισσότερα.

Μη διστάσετε να μας τη διηγηθείτε. Ακόμη και μια μικρή διόρθωση μπορεί να ξαναδώσει όνομα και θέση σε έναν άνθρωπο μέσα στην ιστορία του συλλόγου.

Γιατί φτιάξατε το Ψηφιακό Μουσείο;+

Γιατί η ιστορία του Αρχέλαου δεν βρίσκεται μόνο στα τρόπαια. Βρίσκεται στους ανθρώπους, ακόμη και στις πιο απλές συμμετοχές. Θέλαμε να προλάβουμε τη λήθη και να διασώσουμε όσα δεν είχαν συγκεντρωθεί ποτέ σε ένα ενιαίο αρχείο.

Είναι όλα όσα διαβάζω απολύτως σωστά;+

Όχι απαραίτητα. Συνυπάρχουν διασταυρωμένα γεγονότα, δημοσιογραφικές αναφορές και προσωπικές μαρτυρίες που ακόμη ερευνούμε. Επιδιώκουμε να περιγράφουμε ξεκάθαρα τις αβεβαιότητες και να διορθώνουμε τα σφάλματα όταν βρίσκουμε καλύτερα στοιχεία.

Γιατί δημοσιεύονται και ιστορίες με κενά;+

Επειδή ένα όνομα ή μια ανάμνηση μπορεί να είναι το μοναδικό ίχνος μιας παλαιότερης εποχής. Δεν παρουσιάζουμε τις υποθέσεις ως αποδείξεις. Όπου κρίνεται κατάλληλο, τις διασώζουμε με προσοχή, ώστε να μπορέσουν αργότερα να συμπληρωθούν ή να διασταυρωθούν.

Γιατί αναφέρονται αθλητές χωρίς μεγάλες διακρίσεις;+

Γιατί κάθε συμμετοχή αποτελεί μέρος της ζωής του συλλόγου. Ένα παιδί των ακαδημιών, ένας αθλητής που έπαιξε λίγους αγώνες ή ένας αφανής συντελεστής δεν πρέπει να σβήνει από τη μνήμη επειδή δεν κατέκτησε μετάλλιο.

Πώς μπορώ να διορθώσω ή να συμπληρώσω κάτι;+

Από τη σελίδα συνεισφοράς ή με επικοινωνία στο contact@archelaos.club. Ακόμη και μια απλή πληροφορία μπορεί να οδηγήσει σε σημαντική διόρθωση. Αν έχετε τεκμήριο, αναφέρετε την προέλευση και τυχόν περιορισμούς δικαιωμάτων.

Θα ολοκληρωθεί κάποτε αυτό το αρχείο;+

Ίσως να μην υπάρξει ποτέ μια οριστική, πλήρης εκδοχή της ιστορίας. Κάθε νέα μαρτυρία μπορεί να ανοίγει ένα ακόμη κεφάλαιο. Και αυτό είναι μέρος της ομορφιάς — αλλά και της ευθύνης — ενός ζωντανού μουσείου μνήμης.
