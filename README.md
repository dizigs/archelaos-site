# Γ.Α.Σ. Αρχέλαος Κατερίνης — Ιστοσελίδα

Αυτό το repository περιλαμβάνει την ιστοσελίδα του συλλόγου.

## Δομή αρχείων

- `index.html` — αρχική σελίδα.
- `history.html` — ψηφιακό μουσείο και ιστορία.
- `hall-of-fame.html` — Hall of Fame.
- `70-stigmes.html` — 70 στιγμές.
- `stories.html` — ιστορίες.
- `board.html`, `contact.html`, `sponsors.html`, `retro-matches.html` — επιμέρους σελίδες.
- `images/` — φωτογραφίες περιεχομένου.
- `assets/` — assets και κώδικας πλοήγησης (CSS/JS, έμβλημα).
- `hall-of-fame-people.json` — μοναδική κεντρική βάση βιογραφικών (682 πρόσωπα), για Hall of Fame και συνδέσεις σε άλλες ενότητες.
- `archelaos-person-index.json` — ευρετήριο αναγνώρισης πλήρων ονομάτων και εναλλακτικών γραφών (682 IDs), με ακριβή αντιστοίχιση στην κεντρική βάση.
- `archelaos-person-links.js` — μηχανισμός συνδέσμων και αναδυόμενων βιογραφικών στις υπόλοιπες σελίδες. **Μην μετακινείτε αυτά τα αρχεία χωρίς ενημέρωση των αναφορών.**
- Εικόνες λογοτύπων, favicons, `social-preview.jpg`, `robots.txt`, `sitemap.xml` — διατηρούνται στη ρίζα, ώστε να μη σπάσουν παλιές διαδρομές και μεταδεδομένα.
- `docs/` — εσωτερική τεκμηρίωση και οδηγίες συντήρησης.

## Εκδόσεις

- `v1` — πρώτη επίσημη βάση μετά τον καθαρισμό του repository.
- `v1.1`, `v1.2` κ.ο.κ. — μικρές διορθώσεις και βελτιώσεις.
- `v2`, `v3` κ.ο.κ. — σημαντικές λειτουργικές ή οπτικές αναβαθμίσεις.

Αν προστίθεται έκδοση, καταγράφουμε τις αλλαγές στο `docs/CHANGELOG.md`. Προτού μετακινηθεί οποιοδήποτε αρχείο HTML, CSS, JavaScript, JSON ή εικόνα, πρέπει να ελεγχθούν οι σχετικές διαδρομές και οι εξαρτήσεις της σελίδας.

## Συντήρηση

Κύριος κλάδος: `main`. Τα αρχεία της ιστοσελίδας εξυπηρετούνται με σχετικές διαδρομές, οπότε μετακινήσεις χωρίς ενημέρωση αναφορών μπορεί να προκαλέσουν σφάλματα.
